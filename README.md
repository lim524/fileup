# 파일순서

여러 파일을 수정 시간순으로 정렬해 `1.jpg`, `2.pdf`처럼 번호를 붙이고 하나의 ZIP으로 받는 정적 웹앱입니다. 수정 시간이 같은 파일은 목록에 추가된 순서를 따릅니다. 번호 뒤에 원래 이름을 유지할 수도 있습니다. 브라우저에서 파일을 처리하며 별도의 API와 환경 변수가 필요 없습니다.

## 로컬 실행

프로젝트 폴더에서 `python -m http.server 8000`을 실행한 뒤 브라우저에서 http://localhost:8000 을 엽니다.

## GitHub 및 Vercel

1. 프로젝트 ZIP을 풀고 `index.html`이 있는 폴더의 파일들을 GitHub 저장소 루트에 올립니다.
2. Vercel에서 **Add New → Project**로 해당 GitHub 저장소를 가져옵니다.
3. 프레임워크는 **Other**를 선택합니다. 루트 디렉터리는 저장소 루트를 사용하고 별도 빌드 명령 없이 배포합니다. 출력 디렉터리는 포함된 `vercel.json`이 지정합니다.

ZIP은 압축 없이 파일을 묶습니다. ZIP 한 건은 4 GiB 미만, 최대 65,534개이며 실행 환경에 따라 처리 가능한 용량이 더 작을 수 있습니다.
